# partenaires

> **Rôle :** regroupe les logos et éléments visuels des partenaires (BAG en premier). **Lecteurs :** les agents (pour choisir les fichiers) et l'humain (pour les déposer).

Les fichiers propres à une vidéo sont livrés par Michaël avec la vidéo à monter (chemins dans le brief). Ce dossier garde les outils réutilisables d'une vidéo à l'autre.
