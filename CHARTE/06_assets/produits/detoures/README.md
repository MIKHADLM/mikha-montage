# produits/detoures

> **Rôle :** regroupe les produits détourés utilisables sur tout fond. **Lecteurs :** les agents (pour choisir les fichiers) et l'humain (pour les déposer).

**Fichiers fournis avec chaque vidéo :** les fichiers de ce type sont livrés par Michaël avec la vidéo à monter (chemins dans le brief). Ce dossier n'est pas à remplir d'avance ; il peut servir à archiver ce que Michaël veut réutiliser.

## Ce qu'on y dépose

Un t-shirt par fichier, sur fond transparent, une vue par fichier (face, dos, à plat, etc.) : `[À COMPLÉTER : vues attendues]`

## Format attendu

PNG transparent (canal alpha). Résolution minimale : `[À COMPLÉTER : px]`

## Convention de nommage

`produit_mehomies-flag_[coupe]_[pays]_[vue]_detoure_vNN.png`. Exemple : `produit_mehomies-flag_boxy_[pays]_face_detoure_v01.png`

Convention commune : voir `06_assets/README.md`.
