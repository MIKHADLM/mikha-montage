# produits

> **Rôle :** regroupe les visuels des produits de la collection Mehomies Flag (à confirmer). **Lecteurs :** les agents (pour choisir les fichiers) et l'humain (pour les déposer).

**Fichiers fournis avec chaque vidéo :** les fichiers de ce type sont livrés par Michaël avec la vidéo à monter (chemins dans le brief). Ce dossier n'est pas à remplir d'avance ; il peut servir à archiver ce que Michaël veut réutiliser.

## Ce qu'on y dépose

Deux sous-dossiers : `detoures/` (produits détourés) et `photos/` (photos portées, gros plans). Pas de fichier à la racine de `produits/`.

## Format attendu

Voir le README de chaque sous-dossier.

## Convention de nommage

`produit_[collection]_[coupe]_[pays]_[type]_vNN.ext`. Coupes : `boxy`, `baby-tee`. Voir les sous-dossiers.

Convention commune : voir `06_assets/README.md`.
