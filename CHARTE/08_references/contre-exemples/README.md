# 08_references/contre-exemples

> **Rôle :** conserve ce qu'il ne faut pas faire (vidéos, captures). **Lecteurs :** l'humain et les agents.

## Ce qu'on y dépose

Vidéos ou captures qui montrent un défaut à éviter, avec une note dans `REFERENCES.md` expliquant pourquoi.

## Format attendu

`[À COMPLÉTER : formats acceptés]`

## Convention de nommage

`contre_[sujet]_vNN.ext`. Exemple : `contre_sous-titres-illisibles_v01.png`

Chaque fichier déposé est aussi listé dans `../REFERENCES.md`.
